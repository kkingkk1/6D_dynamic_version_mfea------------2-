# EDA 精英提分反馈的区域对照

## 方法与试验合同

固定自动混合配置 `[2,0,0,0,4,2]`。G4 每个完整整群评估额度选择一次 EDA 或 GA。EDA 拆批时先覆盖前后两组，第二批使用第一批存活后的种群。GA 整群更新并清空 EDA 的分配证据。

- `FEEDBACK` 使用原中位线提分。`COMPLEMENT` 使用同一拆批规则，第二批覆盖第一批未评估的位置。
- `ELITE_FEEDBACK` 保留上一额度的中位线拆批信号。第二批按首批精英提分分配。G5 接受后实际位于 EDA 精英集的样本，计入超过个体原整数收益和额度起始精英线两者较高值的部分。计分归入原排名组，分母包含组内全部评估。
- `ELITE_GATE` 用精英计分判断下一额度是否拆批。上一额度整群更新时取整群证据。上一额度拆批时取均衡首批证据。两种精英模式的反馈差不足一个名额时，第二批补齐。

先在 6,000 / 60 对照三种改法，在 2,000 / 20 比较两个精英模式。选 `ELITE_FEEDBACK` 原规则复测 4,000 / 40、5,000 / 50、10,000 / 100。每个单元使用 seed ID 10–14，同场景匹配种群及单星名义评估上限。复用旧 `FEEDBACK` 和自动混合 A 的逐 seed 结果。A 的比较使用原始终局收益，4,000 / 40 的 A 来自较早运行版本。[上一轮配对证据](../adaptive-batch-allocation/evidence.md)

## 名额、阶段收益与实际评估量

- 6,000 / 60 的旧反馈共转移 244,103 次评估。精英计分降为 17,163 次，其中 2,357 次移向前半组。两者的 EDA 拆批比例分别为 56.0% 和 55.2%。旧反馈首 seed 复跑转移 48,211 次，其中 12 次移向前半组。
- 6,000 / 60 的精英计分相对旧反馈，初排原始收益高 27.2，终局原始收益高 48.4，终局合法收益高 67.8。全场景实际评估均值从 1,759,482 增至 1,776,492。4,000 / 40 与 5,000 / 50 的终局合法收益分别高 13.4 和 34.4，实际评估量分别增加 0.12% 和 1.43%。
- 6,000 / 60 的 `COMPLEMENT` 相对 A 低 31.4 分，接近精英计分版的 −30.2。`ELITE_GATE` 把拆批比例降为 11.5%，相对 A 低 39.8 分。2,000 / 20 的 `ELITE_GATE` 相对 A 低 10.8 分。
- 2,000 / 20 和 10,000 / 100 的精英计分版，相对旧反馈的终局合法收益分别低 16.4 和 3.8。实际评估量分别少 3.33% 与 0.79%。

## 验收与复现

40 次正式运行均完成多星调度、重分配、校准和终局核验。逐次比对首末 seed、命令、单星评估量和预算余额。6,000 / 60 首 seed 的旧反馈回放与归档一致，新增门槛代码后的精英计分回放与原试点一致。两个 ID3 非整群倍数预算探测共核验 140 次单星尾批。Maven 在复测前后各通过 184 项测试。

精英计分保留为 EDA/GA 实验选项。三个中型区域均已缩小原始收益差，平均终局仍低于 A。当前证据覆盖固定 EDA/GA 配置。
