# 最终混合配置 OL 对象选择 P0 证据

## 比较问题与实验条件

在 `[2,0,0,0,4,2]` 下，已排任务 ID 集合能否改变 OL 更新对象，并提高同预算的单星合法调度收益？A 沿用 `FULL/FULL`。B 在 G4 选定父算法后按适应度降序选择前 `k` 个位置，适应度并列时按位置升序。C 保留 B 在各整数收益层的名额，每层优先选任务 ID 集合不同的个体，剩余名额按排名补齐。

实验基于 `7f9f4e1`。按现有初始化分配 `1000-10-0-0-12`，选中任务最多的 4 号卫星，冻结其 78 个任务并按 ID 排序。每个 seed 的三组从同一随机初始种群开始，由固定表 seed 加卫星 ID 初始化随机源。使用 `native200042` 的 `perRun=0..4`，对应 seed ID `10..14`。每组使用独立 JVM，`N=196`、`k=98`、`GREEDY`、G4 过程停滞切换、G5 `PAIRWISE_GREEDY`。每次运行的 19,600 次搜索评估包含 196 次初始化评估。

最终向量做一次额外解码。三组采用同一条终局规则，剔除时长不足的观测，并核验分配、窗口、重复任务与相邻姿态转换。终局耗时单列。`feasible_profit` 是核验方案的任务优先级总和，`raw_profit` 是剔除前调度的整数收益。seed ID 11 的 B/C 同一最优解各剔除任务 849。其窗口末条姿态记录使实际成像只有 23.697 秒，任务要求 24 秒。两组核验前收益为 235，核验后为 226。

## 实现验收

- 同整数收益测试覆盖了不同 ID 集合改变目标，以及集合相同时按排名补齐。两种父算法分别得到独立掩码。
- 手动 Hybrid 入口与批次的首末 seed 日志一致。各 seed 的三组初始种群 SHA-256 和初始适应度一致。A 的首轮与改前回放的掩码、最优解、终态种群、适应度和评估数一致。
- 三组显式设置 `-Dhybcec.fastPathBatchSize=1`。15 次运行中，EDA 和 GA 每次调用都评估全部选中位置。A 每次选 196 个，B/C 每次选 98 个。首轮 C 经 G5 接受 1,416 次，终态 196 个位置的缓存集合与独立重解码一致。
- 实验后 55 项相关回归通过。全量测试的 10 项失败来自基线：9 项需要当前提交缺少的 `native290002` 或 `native270342` 表，另 1 项 `native410000` 的旧断言与已跟踪表不符。

- C 在自身的 990 个选择快照中逐次与 B 的排名规则比较，目标替换数均为 0。五个 seed 的 C−B 收益差均为 0，最优向量和最终种群指纹也逐对一致。所有配对收益差均为平局，方向检验没有有效配对可用。
- A 的收益均值 ± 样本标准差为 238.80 ± 5.26，B 和 C 均为 234.60 ± 5.27。B−A 和 C−A 的配对均值均为 −4.20，未过滤的整数收益配对均值差均为 −2.40。A 与 B/C 的差异包含更新数量、执行路径和 G4 路由轨迹。
- GA 在 A 中调用 163/495 次，在 B 和 C 中分别调用 629/990 次。G4 从历史最优适应度和种群平均适应度的进展判断停滞，实际调用比例随搜索轨迹变化。

## 时间与决策

运行主机为 Intel Core i7-14700KF，检测到 28 个逻辑处理器。`PlanUtils` 按默认 `auto` 并行策略评估种群。

搜索墙钟时间的均值 ± 样本标准差为 A 267.83 ± 5.47 ms、B 254.53 ± 26.24 ms、C 266.04 ± 33.01 ms。五个 C−B 差值依次为 +27.54、+14.17、+15.58、+4.95、−4.69 ms，均值 +11.51 ms。对五个观测配对差穷举有放回重抽样，均值的经验 95% 百分位区间为 [1.75, 20.63] ms。按四慢一快，双侧精确符号检验的 p 值为 0.375。每个实验单元在本机独立 JVM 中计时一次，结果受 JIT 和运行波动影响。C 的集合提取平均为 63.85 ms，按各评估线程的测量值累加。三组终局核验耗时为 1.14–1.57 ms。

本轮覆盖一个场景中的一颗卫星和五个 seed。该规模下的任务集合信号未触发，P0 到单星初筛结束。扩大验证仍要求观察到实际目标替换及正向收益。
