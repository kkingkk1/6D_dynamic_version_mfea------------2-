# EDA 精英反馈首批比例与拆批确认对照

本次先处理现版精英反馈落后的 3,000 任务 / 20 星与 6,000 任务 / 60 星。计划用同一候选覆盖十区。候选在两区的五 seed 均值都达到自动设计 A 后，再到其余八区检查现有优势。

## 复现条件

- 复用[上一轮十区对照](../interior-attitude-feedback-ten-regions/evidence.md)的自动设计 A 和现版 `ELITE_FEEDBACK`。配置均为 `[2,0,0,0,4,2]`，使用排除首尾姿态的程序版本和固定 seed ID 10–14。
- 候选每区每配置五次，全部执行初排、重分配与校准。只按程序保存的终局 `optimizedProfit` 评判。匹配场景、种群和单星名义评估上限。大场景沿用原早停条件，实际使用量由运行日志记录。
- 现版拆批时首批使用一半预算。首轮比较三分之一和三分之二，第二轮比较四分之一与三分之一加连续确认。连续确认要求最近两个完整 EDA 额度的中位线反馈都支持向同一半组转移名额，再允许下一额度拆批。GA 清空这一方向历史，精英计分继续用于第二批名额。

## 终局调度收益

| 设置 | 3,000 / 20 均值 | 6,000 / 60 均值 |
|---|---:|---:|
| 自动设计 A | 4,556.0 | 21,792.4 |
| 现版精英反馈 | 4,554.2 | 21,725.8 |
| 首批三分之一 | 4,549.8 | 21,775.4 |
| 首批三分之二 | 4,553.8 | 21,757.8 |
| 首批四分之一 | 4,540.2 | 21,752.6 |
| 首批三分之一加连续确认 | 4,545.8 | 21,747.6 |

- 3,000 / 20 上，四个候选都低于现版。现版距离 A 为 1.8 分，最接近的候选距离 A 为 2.2 分。
- 6,000 / 60 上，三分之一档比现版高 49.6 分，五对均改善。相对 A 的逐 seed 差约为 −77、−45、−26、+47、+16，均值差为 −17.0。
- 6,000 / 60 上，和单独使用三分之一相比，连续确认将 EDA 完整额度的拆批占比由 57.0% 降到 49.0%，终局均值低 27.8 分。该对照只能判断这项门槛在此配置下的效果。

## 核验与决定

40 次候选运行全部完成。核对了首末 seed、实际 seed、逐次计分、评估量、重分配和校准记录。2,000 / 20 的 seed ID 10 使用现版默认设置回放，终局收益和实际评估数与归档结果一致。Maven 通过 186 项测试。

保留现版精英反馈的设置。四个候选均未进入其余八区的验证。两区用于试验选型，每单元五个配对样本。清单记录逐 seed 差、配对自助区间、标准化效应量及 16 项双侧符号翻转检验的 Holm 校正结果。这些比较均未达到 0.05。
