# Native 290002 seed 下的 410000 对照

## 研究问题

在每个场景使用 native `290002` 的同一组 seed 时，比较 `410000=(4, 1, 0, 0, 0, 0)` 与 `290002=(2, 9, 0, 0, 0, 2)` 的收益比例。

## 协议与完整性

- 场景：ID1-ID10。
- 每个配置：`perRun=0..4`，共 5 次。
- seed：两配置逐场景逐轮使用完全相同的 native `290002` seed。
- 410000：新运行目录 `outputs/410000-native290002-perrun0-4-20260731`。
- 290002：历史 native 输出 `outputs/best-config-10scene-5seed10-14-20260617`。
- 完整性：50 条 410000 记录、50 条 native 290002 记录；seed 交叉核对错误 `0`；配对键错误 `0`；410000 失败记录 `0`。
