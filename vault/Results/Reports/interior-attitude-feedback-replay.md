# 排除首尾姿态后的自适应复测

自动设计 A 与 `ELITE_FEEDBACK` 在修正后的同一排程实现上配对。每区五个同 seed，两组均走完整重分配和校准。唯一指标为程序的终局调度收益。

| 任务 / 卫星 | 自动设计 A | 自适应 | 自适应 − A |
|---|---:|---:|---:|
| 2,000 / 20 | 6,658.0 | 6,700.2 | +42.2 |
| 4,000 / 40 | 14,597.8 | 14,600.4 | +2.6 |
| 5,000 / 50 | 22,378.4 | 22,392.0 | +13.6 |
| 6,000 / 60 | 21,792.4 | 21,725.8 | −66.6 |
| 10,000 / 100 | 18,918.0 | 18,965.0 | +47.0 |

- 自适应四区均值领先，五区等权收益率高 0.06428 个百分点。
- 6,000 / 60 五对都低于 A，2,000 / 20 五对都高于 A。
- 自适应 25 次运行的终局核验均为 0 条短观测。

结果覆盖本次五个区域和同一配置。每个场景五对样本，校正后各场景差异均未达到 0.05。
