# EDA 精英提分反馈的五区域对照

在固定 EDA + GA 配置上，以首批实际存活精英的提分分配第二批 EDA 名额。每个方案与同一场景的旧反馈及归档自动混合 A 配对。

- 三个中型区域相对 A 的原始收益差都缩小。4,000 / 40 从 −16.8 到 −8.4，5,000 / 50 从 −17.2 到 −9.4，6,000 / 60 从 −78.6 到 −30.2。
- 2,000 / 20 相对 A 高 9.0，10,000 / 100 高 80.2。两区的合法收益相对旧反馈分别低 16.4 和 3.8。
- 6,000 / 60 上，精英计分相对旧反馈的合法收益高 67.8，实际评估量增加 0.97%。均匀补齐的原始收益接近精英计分。把拆批条件也收紧到精英提分后，两处试点的原始收益进一步下降。

40 次运行均包含重分配和校准。每个对照使用五个配对 seed。A 只提供原始收益参照，4,000 / 40 的 A 来自较早运行版本。精英计分保留为 EDA/GA 的显式实验选项。
