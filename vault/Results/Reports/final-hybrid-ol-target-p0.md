# 最终混合配置 OL 对象选择单星初筛

## 研究问题

在固定配置 `[2,0,0,0,4,2]` 和相同搜索预算下，利用已排任务 ID 集合选择更新对象，能否改善 4 号卫星的合法调度收益？

## 发现

- C 在 990 次选择中均与同一快照上的 B 排名规则选中相同对象。五个配对的最优解、终态种群和合法收益均一致。
- 改前原路径 A 的首轮回放一致。五个 seed 的合法收益均值为 A 238.8、B 和 C 均为 234.6。G4 调用 GA 的比例从 A 的 32.9% 到 B/C 的 63.5%。全量与子集组的收益差包含更新规模、执行路径和路由轨迹的变化。
- C 的搜索墙钟相对 B 平均增加 11.51 ms，五组中四组更慢。任务集合提取的计时累加各评估线程的耗时。
- seed ID 11 的 B/C 各剔除一个成像时长不足的观测，合法收益为 226。终局核验前，两组的原始整数收益均为 235。

## 限制

证据来自一个场景、一颗卫星和五个 seed。运行时间取各单元的一次 JVM 观测。零替换只描述该场景在固定子集大小和预算下的表现。

## 决策

P0 单星初筛完成。目标替换信号未触发，扩样条件未满足。

## 下一步

出现实际目标替换和正向收益后再评估扩样。4D 搜索以补充验证支持机制有效为前提。
