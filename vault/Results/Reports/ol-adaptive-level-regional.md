# 按全局评估次数计时的自适应种群四区域对照

沿用 ID3 首版，在四个区域各比较五个同种子运行。固定自动设计的 EDA、GA、G4 和 G5，每批自适应选择整群或混合子集。

| 任务 / 卫星 | 自动设计 A 原始收益 | 自适应原始收益 | 差值（胜 / 平 / 负） |
|---|---:|---:|---:|
| 500 / 5 | 2,740.0 | 2,739.0 | −1.0（1 / 1 / 3） |
| 2,000 / 10 | 3,856.4 | 3,854.6 | −1.8（3 / 0 / 2） |
| 2,000 / 20 | 6,665.8 | 6,686.4 | +20.6（3 / 0 / 2） |
| 3,000 / 20 | 4,535.0 | 4,552.8 | +17.8（2 / 0 / 3） |

- 2,000 / 20 的均值提高 20.6 分，折合原始收益率 +0.185 个百分点。
- 3,000 / 20 的两次胜局分别高 73 和 50 分，其余三次较低。
- 四个场景中，GA 的整群平均抽选概率均为 50%。EDA 的对应概率约为 46.7%–47.6%。

20 次自适应运行都完成了重分配、校准和终局合法性核验。复用的 A 归档提供原始收益。四个场景的收益差区间均跨零，现有结果不足以支持跨场景采用这套更新机制。
