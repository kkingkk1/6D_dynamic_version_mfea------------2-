# Auto-Hybrid 两项加速已移植

当前项目使用快照原地重放/回滚和 GREEDY 窗口秒数缓存。保留配置 `[2,0,0,0,4,2]`，不引入参考项目其他算法和配置变更。

- 快速微调复用前缀列表，接受候选先复制，再回滚。GREEDY 仅在调度记录逐项相同时跳过后缀。
- GREEDY 先用缓存秒数检查时间间隔，再读取姿态对象。记录更新后缓存失效；子类和 null 记录保留原访问路径。
